# Power BI Dashboard Setup Guide
### Level 2 – Task 1: Business Intelligence and Reporting

This guide turns the Python/R pipeline output into a real, interactive Power
BI dashboard. It uses `data/processed/churn_for_powerbi.xlsx`, generated by
`python/07_export_for_powerbi.py`, which has 6 ready-to-use sheets:

| Sheet | Purpose |
|---|---|
| `KPI_Summary` | 7 headline KPIs (churn rate, avg charge, etc.) |
| `Customer_Detail` | Full cleaned customer-level table (one row per customer) |
| `Churn_Predictions` | ML churn probability + segment per customer |
| `Risk_Scores` | Composite risk score + tier per customer |
| `By_State` | Pre-aggregated churn/usage metrics per U.S. state |
| `By_Plan_Type` | Pre-aggregated metrics by international/voicemail plan combo |

---

## Step 1 — Get the data
1. Open **Power BI Desktop**.
2. **Home → Get Data → Excel workbook** → select `churn_for_powerbi.xlsx`.
3. In the Navigator, tick **all 6 sheets**, then click **Transform Data** (not
   "Load") so we can set data types first.

## Step 2 — Power Query clean-up (Transform Data / Power Query Editor)
1. On `Customer_Detail`: confirm `churn` is typed as **True/False**, and
   `total_charge`, `total_day_minutes`, etc. are **Decimal Number**.
2. On `By_State`: confirm `churn_rate_pct` is **Decimal Number**, not text.
3. Rename any auto-generated "Column1" headers if Excel added them.
4. Click **Close & Apply**.

## Step 3 — Build the data model (Model view)
1. Go to the **Model** view (left sidebar).
2. Create relationships:
   - `Customer_Detail[customer_id]` → `Churn_Predictions[customer_id]` (1:1)
   - `Customer_Detail[customer_id]` → `Risk_Scores[customer_id]` (1:1)
   - `Customer_Detail[state]` → `By_State[state]` (many:1)
3. Set all relationship cardinalities to **Single** cross-filter direction
   unless you specifically need bidirectional filtering.

## Step 4 — Add the DAX measures
Open `powerbi/DAX_Measures.txt` and paste each measure into
**Modeling → New Measure**, using `Customer_Detail` as the home table.

## Step 5 — Build the dashboard pages

### Page 1: Executive Overview
- **Card visuals** (top row): Total Customers, Churn Rate %, Avg Monthly
  Charge, High-Risk Customers — use the DAX measures.
- **Donut chart**: Churn vs Retained (`churn` field, count of `customer_id`).
- **Bar chart**: Top 10 states by churn rate (`By_State`, sorted descending).
- **Line/area chart**: Churn rate by tenure bucket — create a calculated
  column bucketing `account_length` in Power Query, or reuse
  `visuals/06_churn_trend_by_tenure.png` as a static reference image if you
  prefer not to re-bucket in DAX.

### Page 2: Churn Drivers
- **Clustered bar**: churn rate by `international_plan` and `voice_mail_plan`
  (`By_Plan_Type` sheet).
- **Scatter chart**: `total_day_minutes` vs `customer_service_calls`,
  colored by `churn` — set to `Customer_Detail`.
- **Matrix**: state × plan-type churn rate heatmap using conditional
  formatting (background color scales) on the churn % field.

### Page 3: Predictive & Risk
- **Table/Matrix**: `Risk_Scores` filtered to `risk_tier = "High"`, sorted by
  `risk_score` descending — this is the actionable "call list."
- **Gauge or KPI visual**: average `predicted_churn_probability`.
- **Stacked bar**: customer count by `predicted_churn_risk_tier`
  (`Churn_Predictions` sheet).
- **Slicer**: `customer_segment` so users can filter the whole page by
  cluster.

### Page 4: Filters & Interactivity
- Add slicers for `state`, `international_plan`, and `risk_tier` at the top
  of every page (sync slicers across pages via **Format → Edit
  Interactions** / the Sync Slicers pane).
- Add **drill-through**: right-click a state bar → "Drill through" to a
  detail page filtered to that state's customer list.

## Step 6 — Automate refresh (optional, for "automate report generation")
1. Publish to the Power BI Service (**Home → Publish**).
2. In the Service, go to the dataset → **Settings → Scheduled refresh**, and
   point the data source credentials at the `.xlsx` file's storage location
   (OneDrive/SharePoint works best for scheduled refresh of Excel sources).
3. Under **Alerts**, set a data-driven alert (e.g. "notify me if churn rate
   KPI card exceeds 16%") — this satisfies the "automate email alerts"
   objective without any custom code.

## Step 7 — Export / Share
- **File → Export → PDF** for a snapshot report.
- **Publish to web** or share the `.pbix` link internally for the live
  interactive version.

---
### If you don't have Power BI Desktop installed
Use **Power BI Service** (app.powerbi.com, free account) and upload the
`.xlsx` directly — all the steps above work identically in the browser
version, minus a few advanced Model-view features.
